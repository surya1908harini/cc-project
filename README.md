# Cloud Computing Lab - Video Tutorial Portal ☁️🎓

**Department of Computer Science**  
**Trinity College for Women, Namakkal**

An interactive, responsive web portal providing complete practical guidance, original Aims & Algorithms, source codes, expected outputs, and embedded video tutorials for all 8 Cloud Computing Lab experiments.

---

## 📚 Experiments Covered

1. **Ex No 01:** Google Drive with Spreadsheet and Notes (Google Sheets, Docs, Collaboration) 🎬 *(Video Tutorial Attached)*
2. **Ex No 02:** Linux Virtual Machine (Launching online Ubuntu 22 Linux OS via OnWorks) 🎬 *(Video Tutorial Attached)*
3. **Ex No 03:** Static Website Hosting (Hosting static HTML & CSS via GitHub Pages) 🎬 *(Video Tutorial Attached)*
4. **Ex No 04:** Google Cloud Platform (Cloud Storage Buckets, IAM Sharing, Calendar, To-Do Tasks) 🎬 *(Video Tutorial Attached)*
5. **Ex No 05:** Google App Engine (Python 2.7, GAE Launcher, Localhost 8080 Deployment) 🎬 *(Video Tutorial Attached)*
6. **Ex No 06:** Microsoft Azure (ASP.NET Website Hosting via Visual Studio Publish Profile) 🎬 *(Video Tutorial Attached)*
7. **Ex No 07:** Amazon Redshift with S3 Bucket (AWS S3, IAM Roles, Redshift Cluster, SQL COPY) 🎬 *(Video Tutorial Attached)*
8. **Ex No 08:** Query Using NoSQL Table (MongoDB, NoSQL Booster IDE, CRUD Queries) 🎬 *(Video Tutorial Attached)*

## 🚀 Features

- **Embedded Video Tutorials:** Pre-loaded MP4 practical demonstration videos for all 8 experiments.
- **Interactive Visual Walkthrough Simulator:** Step-by-step visual slide simulations with auto-play and command copy buttons.
- **Full Lab Manual Integration:** Exact Aim and Algorithm steps matching Trinity College for Women lab record.
- **Deploy Ready:** Self-contained static site ready for GitHub Pages hosting.
- **Personal Notes Auto-Saved:** Takes notes per experiment with browser local storage.

## 🌐 Live GitHub Pages Deployment Guide

1. Go to repository **Settings** on GitHub (`https://github.com/surya1908harini/cc-project/settings/pages`).
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In 1–2 minutes, your website will be live at:
   `https://surya1908harini.github.io/cc-project/`
